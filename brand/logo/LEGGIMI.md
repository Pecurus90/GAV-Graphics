# Logo GAV

Metti qui il logo dell'associazione. Preferibile in **SVG** (scala senza perdere
qualita'); in alternativa un **PNG con sfondo trasparente** ad alta risoluzione.

Nome file consigliato:

```
brand/logo/gav.svg      (ideale)
brand/logo/gav.png      (alternativa, sfondo trasparente, >= 600 px di lato)
```

I template lo inseriranno automaticamente nei post (posizione/dimensione gestite
dal layout). Se il logo e' chiaro va bene sulle palette scure; se e' scuro
prepareremo una variante chiara.
